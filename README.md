# Regional Real Estate Data Exploration

Python exploratory analysis of Brazilian real-estate listings, examining regional patterns in property prices and location.

## What this repository demonstrates

Pandas cleaning, parsing latitude/longitude and state fields, price normalization, and plotting with Matplotlib and Plotly.

## Source code

Main example: `Regional Differences in real estates.py`.

## How to explore

Clone or download the repository, open the source file, and review its dependencies and hardware or dataset assumptions. Arduino sketches require the appropriate Arduino IDE board and libraries; Python scripts require the imports and referenced datasets; web exercises can be opened or adapted locally.

## Scope and limitations

The source CSV files are not included. Data paths must be adapted locally. Results depend on the external dataset and have not been independently reproduced here.
